# TurniSync

Versione web condivisibile: <https://dexterlab82.github.io/turnisync/>

TurniSync è una PWA statica. Ogni collega può aprire lo stesso link e installare l’app sulla schermata Home. Le preferenze, i turni elaborati e lo storico anti-duplicati vengono salvati localmente nel browser/dispositivo; non sono condivisi tra colleghi. Gli screenshot vengono elaborati sul dispositivo e non caricati sul server.

Per iPhone: aprire il link in Safari, toccare **Condividi** e scegliere **Aggiungi alla schermata Home**. Per usare una nuova versione dopo averla pubblicata, aprire l’app online e toccare **Aggiorna**.

Questa versione non richiede account. Il formato viene scelto in base alle impostazioni: Google Calendar esporta un CSV con le colonne richieste da Google, mentre Apple Calendar e Outlook esportano un file iCalendar `.ics`. L'importazione CSV in Google Calendar si esegue da calendar.google.com su computer.
